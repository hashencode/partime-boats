# Agent 工作目录

| 目录 | 用途 | 版本管理 |
| --- | --- | --- |
| [memories/](memories/README.md) | 已获批准的新候选，以及本轮已审查保留的存量记录 | 说明与获准保存的非敏感条目可以纳入 Git |
| `tmp/` | 按日期、任务保存临时脚本、日志和中间核对材料 | 仅保留 `.gitkeep`，其余内容递归忽略 |

管理正文见 [经验与记忆维护](../docs/ai/development-rules.md#经验与记忆维护)，任务入口见 [AI 开发导航](../docs/ai/README.md)。本目录不另维护开发规则或验收结论的副本。

整个仓库共用这套目录；monorepo 的记录注明所属应用、模块与适用范围，不为每个包复制一套。本轮存量整理已完成，结果见 [结项记录](../docs/plans/2026-10-22-memory-cleanup-proposals.md)。保留项已结项，按任务相关性查阅，不作为后续待清理队列；新的保存或清理继续按现行规则取得具体授权。

调试与验收截图继续使用 `.artifacts/screenshots/<YYYY-MM-DD-任务>/`。需要版本管理的正式记录放在项目既有文档目录；临时目录中的材料不能作为唯一的长期记录。本次目录补齐不设置定时复核。
