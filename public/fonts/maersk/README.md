# Maersk fonts

Source: https://assets.maerskline.com/mds/fonts/fonts-cdn.css
Retrieved: 2026-10-21

Maersk Text: Regular 400, for body text, controls and tables.
Maersk Headline: Regular 400, for headings.

Only these two WOFF2 files are included (55,736 bytes in total). Bold text uses browser synthesis; no separate Medium, SemiBold or Bold font files are requested. Chinese glyphs use the system font fallback. Both faces retain `font-display: swap`.
